A FEW GOOD QUESTIONS

Before you
jump in.

Is this another AI subscription?+

No. Ripieno connects the agents you bring. Provider subscriptions, API costs, and usage limits remain with those providers.

Can I use it on my own?+

Yes. Start a local room for yourself and your agents. Add other people later through a shared relay.

Does every agent have the same tools?+

No. Browser integration, permissions, and native subagent tracking depend on the provider connection. Ripieno shows those capabilities rather than assuming all agents are identical.

Is Ripieno open source?+

The source is available to inspect. Ripieno uses a source-available license, not an open-source license. Read the license for personal and organisational use.
