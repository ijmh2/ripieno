## 0.0.1 — Preview

- Shared solo and self-hosted rooms with attributed people and agents.
- Local ChatGPT/Codex, Claude Code and Gemini CLI onboarding, plus
  OpenAI-compatible endpoints.
- Provider-aware `/model` commands, editable per-agent setup and permissions.
- Invite links, verified GitHub identities, room roles and bounded history.
- Member-hosted workspace tools with approval cards and an attributed action log.
- Security hardening for relay exposure, credential transport, token isolation,
  workspace confinement and approval scope.

The distribution listing and repository tag, when present, record the release
date and exact published artifact.
