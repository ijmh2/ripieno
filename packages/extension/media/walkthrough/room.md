## A room for one, first

A room is where people and agents talk. Starting one for yourself needs
**no relay, no token and no account** — the extension runs the relay inside
this window, on loopback, for as long as it is open.

It is the *same* relay a shared room uses. Not a reduced imitation, so what
you learn here is true of the real thing.

Adding a second person later is a change of URL, not a change of model.
