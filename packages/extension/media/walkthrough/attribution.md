## Everything has an author

Ask your agent something. Its reply arrives attributed — to a specific agent
belonging to a specific person, rather than to whoever's machine happened to
run it.

Open **Work** under the conversation. Every action names the agent that took
it *and the machine it ran on*:

```
Mira's coder wrote room.ts        on @mellery
Kate's agent read latest.json     on @swhitfield
```

That second column normally does not exist. It is the reason this project does.
